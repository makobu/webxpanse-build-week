# WhatsApp Assistant Plugin

Client-facing product promo and feature summary

Prepared: June 22, 2026

## Product Positioning

The WhatsApp Assistant plugin is the assisted WhatsApp operations layer for WebXpanse and Clarity CRM. It helps a business owner use WhatsApp as a practical work channel for short instructions, daily digests, task reminders, and session-aware follow-through.

This plugin is not just a WhatsApp connection. The WhatsApp channel provides the basic business messaging foundation. WhatsApp Assistant sits above that channel and helps the team use WhatsApp more intelligently after the WhatsApp Business setup is ready.

For a client, the value is simple: WhatsApp Assistant helps turn WhatsApp from scattered messages into guided business action.

## Executive Summary

WhatsApp Assistant helps WhatsApp-led businesses move faster without losing control. It gives the owner and trusted team members a way to receive short CRM digests, send internal instructions, keep assistant sessions visible, and understand when WhatsApp rules require a reply or approved reopen template before the assistant can continue.

Many small businesses already live inside WhatsApp. Customers ask questions there. Sales conversations happen there. Owners check their phone before they check a dashboard. Team members remember tasks in chat, but those tasks do not always become follow-up. WhatsApp Assistant is designed for that reality.

The plugin gives the workspace a setup path for assistant identity, assistant phone number ID, access token, webhook readiness, digest timing, message length controls, authorized WhatsApp numbers, session monitoring, keepalive reminders, approved reopen templates, live test digests, and activity visibility. It is built around controlled communication, not reckless automation.

The result is not "a WhatsApp bot." The result is a safer way to keep business follow-up moving inside the channel the owner already watches.

## What WhatsApp Assistant Is

WhatsApp Assistant is an installable assistant plugin inside WebXpanse and Clarity CRM.

It works after the workspace WhatsApp channel is ready. The WhatsApp channel provides the foundation: the business account, phone number, webhook route, and messaging connection. WhatsApp Assistant adds the operational layer: assistant identity, authorized numbers, compact digests, inbound instruction handling, session rules, keepalive reminders, reopen templates, and activity logging.

In practical terms, the plugin can help with:

- Sending short WhatsApp digests to approved team numbers.
- Receiving internal text instructions from authorized WhatsApp numbers.
- Returning assistant responses in WhatsApp-ready chunks.
- Showing whether outbound and inbound setup are ready.
- Tracking the 24-hour WhatsApp session window.
- Sending keepalive reminders before a session expires.
- Using approved reopen templates when the session has expired.
- Logging assistant messages and digest attempts.
- Giving admins a controlled place to test and monitor setup.

## What WhatsApp Assistant Is Not

WhatsApp Assistant should be sold carefully and honestly.

It is not an uncontrolled customer messaging bot. It is not a shortcut around WhatsApp Business rules. It is not designed to let every customer command the CRM. It does not replace the main WhatsApp channel setup. It does not guarantee a message can be sent if the 24-hour session has expired and no approved template is available.

The better promise is stronger:

WhatsApp Assistant gives the business a safer, more useful assistant inside WhatsApp, with readiness checks and session controls visible before the team depends on it.

## Salient Features

### 1. Marketplace Installation

WhatsApp Assistant is installed from the Marketplace as a modular plugin. This matters because the client can activate it when their business is ready for WhatsApp-led assistant workflows, instead of seeing every possible feature all at once.

The Marketplace profile explains what the plugin does, when to install it, what it depends on, and which setup steps are required before launch.

Client value:

- Easier onboarding.
- Clearer expectations.
- Less confusion between the WhatsApp channel and the assistant layer.
- A visible setup path for administrators.

### 2. WhatsApp Channel Dependency

The plugin requires the core WhatsApp channel to be ready first. This is important because WhatsApp Assistant should not be exposed before the business account, phone number, and webhook foundation are configured.

Client value:

- The assistant starts from a verified channel.
- Setup blockers are visible before launch.
- The business avoids selling a feature before the messaging foundation is ready.

### 3. Assistant Identity Setup

The setup page lets the workspace configure the assistant identity. This includes enabling the WhatsApp Assistant, setting the assistant phone number, saving the phone number ID, and storing the access token required for outbound assistant messaging.

Client value:

- The assistant has a clear sending identity.
- Admins know which WhatsApp number is connected.
- Outbound readiness is based on actual credentials, not guesswork.

### 4. Webhook Readiness

WhatsApp Assistant depends on webhook readiness for inbound instructions and status awareness. The system checks whether inbound routing is available and whether the assistant webhook target can be identified.

Client value:

- The assistant can receive messages from authorized numbers.
- Admins can see whether inbound processing is ready.
- Failed or incomplete setup is easier to diagnose.

### 5. Authorized Number Control

The assistant works with mapped, authorized WhatsApp numbers. It does not treat every incoming WhatsApp message as a command. When a message arrives, the system checks whether the sender is authorized before assistant processing continues.

Client value:

- Better control over who can give the assistant instructions.
- Lower risk of random users triggering internal workflows.
- Clearer separation between customer WhatsApp traffic and internal assistant use.

### 6. Internal Text Instruction Handling

Authorized users can send text instructions to the assistant through WhatsApp. The message is processed by the assistant handler, and the response is sent back in WhatsApp-ready format.

Client value:

- Owners can act from the channel they already check.
- Team members can give short instructions without opening another screen.
- The assistant can support operational follow-through while keeping access limited.

### 7. Media Guardrails

If a user sends a media-only assistant command, the system responds that text instructions are required. This is a simple but important guardrail.

Client value:

- Users receive clear feedback.
- The assistant does not pretend it can process unsupported input.
- The workflow stays reliable and predictable.

### 8. WhatsApp-Ready Reply Formatting

The assistant formats replies for WhatsApp. Long responses are summarized and split into chunks. If there is too much detail, the user is directed back to the CRM for the full view.

Client value:

- Messages are easier to read on a phone.
- Long AI output does not overwhelm the chat.
- WhatsApp stays useful for quick action, while the CRM remains the full record.

### 9. Daily WhatsApp Digests

The plugin can send daily WhatsApp digests to approved recipients. The digest pulls from CRM task data and AI Coach recommendations, then formats the result into short WhatsApp messages.

Client value:

- The owner sees what matters without hunting through the CRM.
- Overdue tasks and due-today work stay visible.
- AI Coach quick wins can reach the user where they are likely to see them.

### 10. Digest Timing

Admins can configure a digest time, such as a morning send time. The scheduled worker checks whether the digest is enabled, whether the time has arrived, and whether the recipient has already received the digest that day.

Client value:

- The business can create a dependable daily rhythm.
- The owner gets priorities at the right time.
- Duplicate daily digests are avoided.

### 11. Message Length Controls

The setup includes maximum message character and chunk controls. This keeps WhatsApp digests and replies short enough to be useful.

Client value:

- Better mobile readability.
- Less message clutter.
- More predictable assistant behavior.

### 12. Session Awareness

WhatsApp has session rules. The assistant tracks session states such as open, expiring soon, and expired requiring reopen. This helps the business understand when free-form assistant messages can continue and when a user reply or approved template is required.

Client value:

- Fewer confusing message failures.
- Better respect for WhatsApp Business rules.
- Clearer operations around the 24-hour session window.

### 13. Keepalive Reminders

When a session is close to expiring, the session worker can create reminders. The reminder tells the mapped user to send a WhatsApp message to keep the assistant window open.

Client value:

- The team can keep useful assistant access alive.
- Session problems are handled before they become surprises.
- Owners understand what action is needed.

### 14. Reopen Template

When a session has expired, WhatsApp Assistant can use a configured reopen template. This requires the proper template name, language, and template values.

Client value:

- The business can restart the conversation according to WhatsApp rules.
- Admins can prepare the template before rollout.
- The assistant does not rely on illegal or unreliable message behavior.

### 15. Auto Reopen Controls

The plugin supports auto reopen behavior when the session has expired and the reopen template is ready. If the template was already sent, the system avoids repeatedly sending the same reopen attempt.

Client value:

- Less manual session management.
- Fewer repeated reopen messages.
- Better control over when the assistant waits for the user to reply.

### 16. Live Test Digest

The setup page includes a live test digest action. This lets the workspace test the configured assistant path before depending on it for daily operations.

Client value:

- Admins can confirm the setup before team rollout.
- Problems are caught earlier.
- The first experience feels more professional.

### 17. Readiness Checks

WhatsApp Assistant includes readiness checks for enabled status, outbound credentials, webhook readiness, digest controls, and reopen template configuration.

Client value:

- Admins can see what is ready and what still needs setup.
- The business avoids hidden configuration risk.
- Support conversations become easier because blockers are visible.

### 18. Activity Visibility

The assistant logs inbound messages, outbound replies, digest attempts, session events, keepalive reminders, reopen template events, and message statuses when the related tables are available.

Client value:

- Better accountability.
- Easier troubleshooting.
- More confidence that the assistant is doing what it should.

### 19. Background Digest Worker

The digest worker can be run safely from scheduled jobs. It checks whether digests are due, sends them to mapped recipients, and records success, failure, or skipped status.

Client value:

- Daily digests can run without manual effort.
- Admins can monitor job health.
- The business gets a repeatable operating rhythm.

### 20. Background Session Worker

The session worker monitors session state. It can send keepalive reminders, handle expired sessions, and attempt reopen templates when configured.

Client value:

- Session continuity is managed proactively.
- The assistant becomes more dependable.
- Operators do not need to manually check every session.

### 21. Workspace-Aware Routing

The webhook routing can resolve the correct workspace for an incoming assistant message, activate that workspace context, and process the message through the assistant layer.

Client value:

- Multi-workspace behavior is cleaner.
- Assistant messages can be handled in the right business context.
- The system avoids mixing assistant activity across workspaces.

### 22. Runtime Usage Metrics

The Marketplace performance layer can track WhatsApp Assistant usage, including recent messages, recent digests, active sessions, and latest message status.

Client value:

- Admins can see whether the assistant is being used.
- Teams can measure whether setup is producing activity.
- Product adoption can be discussed with real signals.

### 23. AI Context Support

WhatsApp Assistant is connected to the system's assistant context. The daily digest can include tasks and AI Coach recommendations, giving the owner more than a plain reminder list.

Client value:

- The assistant helps identify priorities, not just send messages.
- AI guidance appears in a practical format.
- The owner receives simple next-step prompts instead of another dashboard to inspect.
