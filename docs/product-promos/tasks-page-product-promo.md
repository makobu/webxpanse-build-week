# Clarity CRM Tasks Page

Client-facing product promo and feature summary

Prepared: June 16, 2026

## Product Positioning

The Clarity CRM Tasks page is the follow-through center for the business. It helps teams turn customer promises, sales actions, onboarding steps, AI suggestions, and internal commitments into visible work that has an owner, priority, due date, and outcome.

This page is not just a to-do list. It is the place where Clarity helps the team answer a practical question: what commitment needs attention next?

For clients, the Tasks page creates discipline around execution. It keeps important work from disappearing into memory, chat messages, notebooks, or scattered reminders. It gives each user a focused queue of work, highlights overdue commitments, connects tasks back to customers, and supports AI-assisted follow-through with human review.

## Executive Summary

The Tasks page gives users a clear operating view of the work they are responsible for. By default, it focuses on the current user's tasks, so each person starts with their own commitments instead of a noisy company-wide list. Users with broader permission can review tasks across other assignees.

Tasks can be searched and filtered by status, priority, assignee, and overdue state. The page groups matching work into Overdue, Due Soon, No Due Date, Completed, and Cancelled sections, making the next action easier to spot.

Each task can carry a title, description, contact link, assignee, creator, status, priority, due date, notes, documents, subtasks, source information, and AI evidence. The task detail page supports completion review, checklist progress, reassignment, notes, file uploads, AI diagnostics, and evidence-aware completion.

The intention is simple: help teams finish the right work at the right time, especially follow-up work that protects customer trust and revenue.

## What The Page Is Built To Do

The Tasks page is intended to help teams:

- See open commitments in one focused queue.
- Start with work assigned to the current user by default.
- Find overdue and due-soon work quickly.
- Create tasks with a clear owner, contact, priority, status, and due date.
- Connect tasks to customer records, deals, targets, notes, files, and AI guidance.
- Keep follow-up work visible until it is completed or cancelled.
- Review AI-created or Clarity-suggested work before marking it done.
- Track evidence, subtasks, notes, documents, and completion decisions in one place.
- Reassign work safely based on permissions.
- Feed completed task outcomes back into customer intelligence, target intelligence, AI learning, and automation.

## Salient Features

### Focused Task Queue

The page opens into a clean task queue. It defaults to tasks assigned to the current user, which keeps the page personal and actionable. A user can immediately see what they are responsible for instead of being overwhelmed by the full team's workload.

When permitted, managers and administrators can filter by assignee to review work across users. This supports both personal productivity and team oversight.

### Smart Work Grouping

Tasks are grouped into practical work sections:

- Overdue: past due and still open.
- Due Soon: dated work that should move next.
- No Due Date: work that needs timing before it can be ranked.
- Completed: finished work matching the current filters.
- Cancelled: work removed from active execution.

This grouping helps users understand urgency without needing to interpret a long table. Overdue work is visually called out, due work stays visible, and undated work is separated so the team can add timing.

### Search And Filters

The Tasks page includes filters for search, status, priority, assignee, and overdue work. It also displays active filter chips so users know exactly what view they are looking at.

Default filtering keeps the queue focused on open work. Users can intentionally switch to Completed or Cancelled when they need to review historical task activity.

### Client-Friendly Empty State

If no tasks match the current view, the page does not simply go blank. It explains that no tasks were found and encourages the user to create a manual onboarding task or follow-up step.

This supports the product intention of turning empty space into guidance: if there is no visible next commitment, create one.

### Clear Task Rows

Each task row gives the user the important facts at a glance:

- Task title.
- Short description.
- Due date or "No due date."
- Assignee.
- Related contact.
- Priority.
- Status when relevant.
- Source label, such as manual, Clarity, or AI.
- Evidence marker when completion was supported by evidence.
- View and edit actions.

This allows users to scan the queue and choose the next task without opening every record.

### Manual Task Creation

The Create Task flow helps users define the work in one pass. A task can include title, description, contact, assignee, priority, status, and due date.

This makes the page useful for everyday work such as:

- Follow up with a lead.
- Call a customer.
- Prepare a quote.
- Send an invoice.
- Review a proposal.
- Complete onboarding setup.
- Confirm a meeting outcome.
- Check whether a customer replied.

### Contact-Connected Follow-Up

Tasks can be linked to contacts. When a task is associated with a contact, it becomes part of that customer's working story. Updates can log activity and refresh contact intelligence so the CRM understands what is happening around that relationship.

For clients, this is a major value point. Follow-up is no longer just a private reminder. It becomes part of the customer record.

### Ownership And Assignment Controls

The page respects task permissions. Users need task read access to view the page and task write access to create or edit work. Reassignment is controlled separately.

The system also filters assignable users based on permissions. This matters when work is sensitive, domain-specific, or AI-assigned. It helps keep the right work with the right people.

### Task Detail Page

Opening a task reveals a richer execution workspace. The detail page shows:

- Status, priority, due date, assignee, contact, and source.
- Description and context.
- Primary actions such as Mark Done, Review Completion, Detect Completion, or Reopen.
- Completion evidence when review is required.
- AI guidance and completion rules for AI-created tasks.
- Checklist steps and subtask progress.
- Notes and private notes.
- Documents and file uploads.
- Metadata such as creator, creation date, completed date, and last review.
- Reassignment controls when permitted.
- AI evidence diagnostics when relevant.

The detail page turns a task from a simple reminder into a small work file.

### Checklist And Subtasks

Tasks can include subtasks. The detail page shows checklist progress, such as 2 out of 5 steps done, and lets users check off individual steps.

For guided or AI-created tasks, this is especially useful because a broad recommendation can be broken into smaller, finishable actions. When checklist evidence supports completion, the system can help keep the parent task in sync.

### Evidence-Aware Completion

The Tasks page includes a careful completion review flow. For AI-created or auto-detectable tasks, the system can review evidence before marking the task done.

Evidence may include signals such as:

- Checklist completion.
- Customer reply received.
- Invoice state reached.
- Billing setup completed.
- Deal stage reached.
- Dependency task completed.

The review can show evidence found, missing evidence, conflicts, confidence level, and a recommended action. A user can mark the task done, keep it open, detect again, or mark it done anyway with judgment.

This is important because it supports safe AI assistance. The system helps review the facts, but the human still decides when needed.

### Notes And Documents

Each task can hold notes and documents. Users can add a note, mark it private, upload supporting files, download files, or delete files when permitted.

This keeps context close to the work. A task can carry the instructions, evidence, customer details, screenshots, documents, or reasoning needed to complete it properly.

### AI And Clarity Follow-Through

Tasks can come from manual work, Clarity suggestions, AI Coach recommendations, plugins, or automated workflows. The page clearly labels the source so users understand whether a task was created manually or suggested by the system.

When tasks are completed, reopened, reassigned, or updated, the system can record outcome signals, refresh intelligence, notify assignees, trigger lifecycle events, and support future AI learning.

The result is a feedback loop: the system suggests work, the user completes or corrects it, and Clarity learns from what actually happened.

### Beginner Guidance And Page Education

The Tasks page includes beginner work-surface guidance. In beginner mode, Clarity can tell the user what to focus on, such as finishing an overdue follow-up or creating one clear task if the queue is empty.

The page can also include a Tasks page guide video titled "How to use Tasks." This helps new users understand the page without needing separate training.

## Why Clients Should Care

The Tasks page is valuable because most business value is lost in the gap between "we should do this" and "we actually did it."

A CRM can store customers, but tasks make action visible. They help a team protect customer promises, follow up on time, and turn recommendations into execution.

For a client, the practical value is:

- Fewer forgotten follow-ups.
- More accountable ownership.
- Cleaner handoff between team members.
- Better customer memory.
- Clearer daily focus.
- Better evidence before closing work.
- More useful AI because the system learns from real outcomes.

## Product Intentions

The Tasks page is intentionally built around five product goals.

First, it makes commitments visible. If something matters, it should have a task, an owner, and a next step.

Second, it protects follow-up discipline. The page highlights overdue work and due-soon work so customer promises do not quietly disappear.

Third, it connects execution to the customer story. A task can link to a contact, carry notes and files, update activity history, and support relationship intelligence.

Fourth, it keeps AI accountable. AI can suggest, create, detect, and review task completion, but evidence and human judgment remain part of the process.

Fifth, it turns completed work into learning. Task outcomes can feed Clarity's future recommendations, automation confidence, and follow-through logic.

## Client-Facing Value Proposition

Clarity CRM's Tasks page helps teams finish the work that protects customers and revenue. It gives every commitment a place to live, shows what is overdue or due next, connects work back to contacts, and lets AI assist with follow-through without removing human control.

For a client, the promise is not "manage tasks." The promise is:

Your team will know what needs to happen next, who owns it, when it is due, what customer it affects, and whether there is enough evidence to mark it done.
