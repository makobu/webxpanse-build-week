This pass avoided broad refactors and kept code changes to a small constructor-injection cleanup in draft modules.

## Small Cleanup Completed

- Updated `modules/DraftTemplates.php` to keep one `WorkspaceScopeService` instance per module object instead of constructing it inside `requireWorkspaceId()`.
- Updated `modules/DraftReview.php` to reuse the same `WorkspaceScopeService` for workspace resolution and contact workspace assertions.
- This is intentionally narrow: behavior and SQL remain unchanged, but the modules are now easier to unit test with an injected workspace scope.
